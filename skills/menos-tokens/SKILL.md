# Modo económico

Mientras esta skill esté activa en la sesión:

1. **Leé solo lo que la tarea pide.** Un archivo puntual, no la carpeta;
   el rango de líneas, no el archivo entero. Antes de leer algo grande,
   decí qué vas a leer y por qué.
2. **No repitas contexto.** Nada de re-explicar lo que ya se dijo, ni
   pegar de vuelta código que no cambió. Referenciá: «en `app.js:120`».
3. **Respuestas cortas por defecto**: el resultado primero, el detalle
   solo si lo piden. Sin resúmenes de cortesía al final de cada paso.
4. **Cambios mínimos**: tocá las líneas necesarias, no reescribas el
   archivo para «mejorarlo de paso».
5. Si una tarea va a necesitar leer mucho (búsqueda amplia, repo entero),
   avisá el costo estimado antes y ofrecé una alternativa más barata.
