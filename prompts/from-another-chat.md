# from-another-chat.md · Migrar una idea definida en otro chat

Los chats no se leen entre sí, así que el puente lo hacés vos en 2 pasos:

**Paso 1 — en el chat viejo**, pegá esto:

```
Resumime este chat para arrancar el proyecto en otra sesión con SDD.
Formato: Proyecto (1 línea) · Problema que resuelve · Decisiones ya
tomadas (stack, alcance, restricciones) · Features habladas (lista
corta) · Pendientes/dudas abiertas. Máximo 30 líneas.
```

**Paso 2 — en el chat nuevo**, pegá el SDD-MASTER (o adjuntá el archivo) + esto:

```
Adjunto el SDD-MASTER. Aplicalo como greenfield (§6.1) usando el
contexto de abajo, que viene de otro chat donde ya definimos la idea.
Tomá las "Decisiones ya tomadas" como definitivas (no las re-preguntes)
y usá el cuestionario socrático (R04) SOLO para los pendientes y lo
que falte.

--- CONTEXTO DEL OTRO CHAT ---
[pegar acá el resumen del paso 1]
```

Resultado: el proyecto nuevo arranca con SDD completo sin repetir la conversación anterior.
